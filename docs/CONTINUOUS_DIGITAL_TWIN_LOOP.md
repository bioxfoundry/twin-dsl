# Continuous Digital Twin loop

## Kanoniczny cykl

```text
manager/customer/project/internet/archive
→ conversion and immutable resources
→ research projections
→ todo2code development evidence
→ runtime observations
→ mathDSL gates
→ twinDSL
→ sceneDSL/OpenUSD
→ receipts and feedback
→ next research snapshot
```

Research, development and execution are separate bounded contexts. A source claim cannot become an observed runtime fact without a validator. A development report cannot become DONE without code/test evidence. A scene candidate cannot replace `current` when `ScenePublishAllowed=false`.

## Stable no-change

The iteration identity includes:

- projectDSL hash;
- research resource snapshot;
- todo2code graph fingerprint;
- observationDSL snapshot.

Timestamps generated by the runtime are not inputs to no-change detection. Feedback content is semantically stable and therefore does not create an endless self-referential hash chain.
