# Customer Biofoundry requirements

The customer supplied dimensions for two bioreactors, one buffer tank, a clean bench and an incubator. All dimensions are metres. The clean bench and incubator belong to the clean zone. Reactors and the buffer tank belong to the dirty process zone.

The requested 3D environment is a conceptual operational view, not a certified CAD model. Every object must retain a citation to the customer specification and current project state.
