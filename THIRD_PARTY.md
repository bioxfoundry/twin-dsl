# Existing projects and standards used

- `https://github.com/semcod/todo2code` — Intent Evidence DSL, OpenRouter structured outputs, evidence graph, Intent vs Reality and hash-bound plans. Integrated by CLI; not vendored.
- `https://openrouter.ai/docs/` — chat completions, strict JSON Schema structured outputs, provider parameter requirements and optional response-healing.
- `https://clickhouse.com/docs/` — analytical/full-text read projection. Compose and table schema included.
- `https://docling-project.github.io/docling/` — document conversion and OCR service. Container included.
- `https://www.sitemaps.org/protocol.html` — `urlset`, `sitemapindex` and `<loc>` discovery semantics.
- `https://openusd.org/` — scene target. Starter emits deterministic USDA text without bundling OpenUSD binaries.
- Subactor AQL/OQL/URI Process/TestQL/EQL — authority, execution and evidence gates. Source documentation included under `docs/source/`.
- Protobuf/gRPC/Buf — service contracts supplied under `proto/`.

No third-party source code is vendored by this package. The example ZIP archives contain only original fixture text.
